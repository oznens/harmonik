# kaynaklar

Harmonik formasyonlarla ilgili ham kaynaklar buraya konur.

## PDF Yükleme

- PDF dosyalarını doğrudan bu klasöre yükle (GitHub web arayüzünden veya git ile).
- Dosya adlarını anlamlı ver: `scott-carney-harmonic-trading.pdf` gibi.
- PDF'ler okunduktan sonra `notlar/` altında yapılandırılmış notlara dönüştürülür.

## Notlar

- **Dosya boyutu:** Tek tek 50 MB altındaki PDF'ler git için sorun değil.
  Çok sayıda büyük dosya olursa Git LFS'e geçilebilir.
- **Büyük PDF'ler:** 10 sayfadan uzun PDF'ler sayfa aralığıyla, parça parça okunur.
- Sadece PDF değil; ekran görüntüsü, makale veya metin dosyası da konabilir.
