# notlar

Kaynaklardan çıkarılan yapılandırılmış notlar — projenin kalıcı bilgi bankası.

Her harmonik formasyon için tipik olarak şunlar tutulur:

- Formasyonun tanımı ve yapısı (X, A, B, C, D noktaları)
- Fibonacci oranları (her bacak için)
- Geçerlilik kuralları ve toleranslar
- Boğa (bullish) / ayı (bearish) varyantları
- İşlem (giriş/stop/hedef) mantığı
- Kaynak referansı (hangi PDF, hangi sayfa)

Kaynaklar `kaynaklar/` klasörüne yüklendikçe bu klasör doldurulacak.
