# AB=CD Formasyonu

**Tip:** Temel yapı — TÜM harmonik formasyonların iskeleti.
**Noktalar:** A, B, C, D (4 nokta, 3 bacak: AB, BC, CD).

## Tanım

İlk fiyat hareketi (AB) kısmen geri çekilir (BC), ardından geri çekilme
noktasından AB'ye eşit uzunlukta bir hareket gelir (CD). Yani AB bacağı ≈ CD
bacağı. C noktası formasyonun tamamlanma seviyesini belirleyen anahtardır.

```
Boğa (bullish):           Ayı (bearish):
A                              B   D
 \      C                     / \ / \
  \    / \                   /   C   \
   \  /   \                 A         \
    B      D                           (devamı aşağı yok; tepe)
```

## Yapı ve Oranlar

| Bacak | Ölçü | Aralık |
|-------|------|--------|
| AB | İlk hareket | — (referans bacak) |
| BC | C = AB'nin retracement'i | **0.382 – 0.886** (0.618 tercih) |
| CD | D = BC'nin projeksiyonu | **1.13 – 3.618** (C'ye bağlı, resiprokal) |
| AB ↔ CD | Uzunluk eşitliği | CD ≈ AB (equivalent) |

C retracement → BC projeksiyon resiprokal eşleşmesi
(bkz. `00-temel-kavramlar.md`):

| C = | BC = |
|-----|------|
| 0.382 | 2.24 / 2.618 |
| 0.50 | 2.0 |
| 0.618 | 1.618 |
| 0.707 | 1.41 |
| 0.786 | 1.27 |
| 0.886 | 1.13 |

## Geçerlilik Kuralları

1. Her fiyat bacağının eşit olduğu minimum AB=CD tamamlanması şarttır.
2. C noktası retracement'i 0.382–0.886 arası olabilir; **0.618 tercih edilir**.
3. BC projeksiyonu 1.13–3.618 arası; C noktasına bağlıdır.
4. BC projeksiyonu, formasyonun tamamlanma noktasıyla **yakın bölgede
   buluşmalı** (PRZ'yi sıkılaştırır).

## Perfect AB=CD

1. C noktası tam **0.618** retracement (AB bacağının).
2. **1.618** BC projeksiyonu.
3. Her bacak zaman olarak eşit süreli (simetri).

Boğada D, PRZ'nin en alt sayısı; ayıda en üst sayısı olmalı.

## Alternate AB=CD

CD bacağı AB'den uzun olduğunda kullanılır (uzamış yapı):
- **1.27 AB=CD** → CD = AB × 1.27
- **1.618 AB=CD** → CD = AB × 1.618

Kullanım: Bat formasyonu genelde 1.27 AB=CD içerir; Crab/Butterfly uzamış
satışlarda alternate AB=CD kullanır. Gartley'de ise AB=CD genelde eşittir
(equivalent).

## Reciprocal AB=CD

Standart AB=CD'nin bir varyantı; Shark ve 5-0 formasyonlarında PRZ tanımlamak
için kullanılır.

- Yerleşik bir trend içindeki ilk ters-yön (counter-trend) hareketle ölçülür.
- Tembel bir "Z" veya "S" harfine benzer.
- Kesin değil, **yaklaşık (approximation)** bir ölçüdür; diğer harmonik
  ölçülerle desteklenmelidir.
- AB projeksiyonu ile resiprokal retracement eşleşir (ör. 1.618 AB
  projeksiyonu → ~0.618 AB retracement, D noktasında).
- CD bacağı, AB'nin eşdeğer tamamlanma noktasını en az test eder.

## Notlar

- AB=CD tek başına bir işlem sinyali olarak görülmemeli — "tamamlanan her
  AB=CD'de işlem yapmak saçmadır" (Carney). Diğer Fibonacci retracement/
  projeksiyonlarıyla, net formasyonlarla desteklenmelidir.
- Ama en önemli kavram: AB=CD tüm harmonik formasyonların temel iskeletidir.
